# Sungji Hub

스마트 성지 웹사이트 전체 재구축 프롬프트

기존에 개발하던 「스마트 성지」 웹사이트를 처음부터 다시 구축해줘.

스마트 성지는 성지중학교 학생들이 학교생활에 필요한 정보를 쉽고 빠르게 확인할 수 있는 정보 공유 웹사이트다.

이번 버전은 학생 계정을 사용하지 않고 학년과 반만 선택하면 바로 이용할 수 있는 구조로 만든다.

1. 핵심 이용 방식

학생이 사이트에 접속하면 다음 순서로 이용한다.

사이트 접속 → 학년 선택 → 반 선택 → 해당 학년/반 대시보드

회원가입이나 학생 로그인은 절대 사용하지 않는다.

학생 이용 흐름

스마트 성지 접속

3. 학년/반 선택 저장

학생이 선택한 학년과 반을 브라우저의 로컬 저장 기능을 이용해서 저장한다.

예를 들어:

학년: 2학년
반: 5반

을 선택했다면 다음 방문 시 자동으로 2학년 5반 대시보드로 이동할 수 있도록 한다.

단, 사용자가 언제든지 변경할 수 있도록 대시보드에

[ 학년/반 변경 ]

버튼을 제공한다.

학년/반 정보는 회원 계정과 연결하지 않는다.

7. 급식 기능

학교 급식은 NEIS(나이스) Open API를 이용해서 자동으로 불러오도록 구현한다.

기존에 사용하려고 했던 방식처럼 API 인증키를 환경변수로 연결해서 사용한다.

중요

API 인증키를 프론트엔드 코드에 직접 작성하지 않는다.

다음과 같은 방식으로 환경변수를 사용한다.

NEIS_API_KEY=사용자의_인증키

실제 환경변수 이름은 프로젝트 구조에 맞게 안전하게 설정한다.

Lovable의 환경변수/Secrets 기능을 사용해서 API 키를 안전하게 관리한다.

8. NEIS API 급식 데이터

NEIS API에서 성지중학교의 급식 정보를 가져와서 자동으로 표시한다.

급식 화면에서는 최소한 다음 정보를 제공한다.

날짜

중식

메뉴

원산지/알레르기 정보가 API에서 제공되는 경우 표시

급식이 없는 날 표시

예:

오늘의 급식

🍚 8월 29일 중식

• 메뉴 1
• 메뉴 2
• 메뉴 3
• 메뉴 4
• 메뉴 5

급식 정보는 매번 관리자가 직접 입력하는 방식이 아니라 NEIS API에서 자동으로 가져오는 방식으로 구현한다.

9. 급식 API 오류 처리

NEIS API 요청이 실패했을 경우 사용자에게 API 오류 메시지를 그대로 노출하지 않는다.

예:

급식 정보를 불러오지 못했습니다. 잠시 후 다시 시도해주세요.

API 데이터가 없는 날짜라면:

오늘은 등록된 급식 정보가 없습니다.

와 같이 자연스럽게 표시한다.

10. 오늘의 시간표

시간표는 학년 + 반별로 독립적으로 관리한다.

즉,

1학년 1반
1학년 2반
...
1학년 8반

2학년 1반
...
2학년 9반

3학년 1반
...
3학년 9반

각각의 시간표를 등록할 수 있어야 한다.

총 26개 학급을 독립적으로 관리할 수 있도록 데이터 구조를 설계한다.

학생이 2학년 5반을 선택했다면 2학년 5반의 시간표만 표시한다.

11. 시간표 관리

관리자 페이지에서

학년 → 반 → 요일

순서로 선택해서 시간표를 관리할 수 있도록 한다.

예:

학년: 2학년
반: 5반
요일: 월요일

선택 후 각 교시의 과목을 등록할 수 있다.

시간표 예시:

교시월화수목금1교시국어수학영어과학체육2교시수학영어국어사회수학3교시영어과학체육국어영어

시간표는 관리자 페이지에서 자유롭게 추가/수정/삭제할 수 있어야 한다.

17. 관리자 인증

학생용 로그인은 만들지 않는다.

관리자 페이지에 접근할 때만 관리자 인증을 요구한다.

관리자는 하나의 관리자 계정을 기준으로 운영할 수 있도록 한다.

관리자 비밀번호 등의 민감한 정보는 프론트엔드 코드에 직접 노출하지 않는다.

18. 데이터 구조

학년과 반을 반드시 데이터의 핵심 식별값으로 사용한다.

예:

grade: 1
class: 3

또는

grade: 2
class: 5

시간표와 과제는 반드시 grade + class를 기준으로 구분한다.

예:

1학년 8반
2학년 8반
3학년 8반

이 세 학급은 서로 완전히 다른 데이터로 취급해야 한다.

19. 총 학급 수

현재 학교 구조는 다음과 같다.

2학년: 9개 반

이 구조를 프로젝트 전체에서 일관되게 사용한다.
